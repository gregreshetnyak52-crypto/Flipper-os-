# Flipper OS Toolkit

Моё приложение для [Flipper Zero](https://flipperzero.one): набор из шести
инструментов, объединённых общим меню. Написано на C под официальную прошивку
и собирается как внешнее приложение (`.fap`).

| Модуль | Что делает | Управление |
|---|---|---|
| **Stopwatch** | Секундомер с сотыми долями и двумя последними кругами | OK — старт/стоп, ← — круг (идёт) / сброс (стоит) |
| **Dice Roller** | Бросок от 1 до 4 костей d4…d100 с анимацией и вибро | ↑/↓ — число граней, ←/→ — количество, OK — бросок |
| **Morse Beacon** | Передаёт сообщение азбукой Морзе светодиодом, вибро или звуком | ←/→ — сообщение, ↑ — выход сигнала, ↓ — повтор, OK — старт/стоп |
| **Snake** | Классическая «Змейка» 32×14 с ускорением и рекордом | Стрелки — поворот, OK — старт/пауза |
| **Tally Counter** | Счётчик с шагом 1…100 | OK — плюс, ← — минус, удержание ← — сброс, ↑/↓ — шаг |
| **System Info** | Имя устройства, заряд, напряжение, ток, температура АКБ, свободная память, аптайм, дата и время | — |

Кнопка «Назад» в любом модуле возвращает в меню, в меню закрывает приложение.

## Сборка

Нужен [ufbt](https://github.com/flipperdevices/flipperzero-ufbt), официальный
SDK для внешних приложений:

```sh
pip install --upgrade ufbt
cd flipper_os
ufbt                # собрать dist/flipper_os.fap
ufbt launch         # собрать, загрузить и запустить на Flipper по USB
```

Для прошивки из dev-ветки: `ufbt update --channel=dev`.

Готовый `flipper_os.fap` можно взять и в артефактах GitHub Actions
(workflow **Build FAP**). Скопируйте его через qFlipper или на SD-карту в
`apps/Tools/`, после чего приложение появится в **Apps → Tools → Flipper OS Toolkit**.

## Структура

```
flipper_os/
├── application.fam      # манифест приложения
├── flipper_os.png       # иконка 10×10
├── flipper_os.c         # точка входа, ViewDispatcher и главное меню
├── flipper_os_i.h       # общие типы приложения
└── modules/             # по одному View на модуль
    ├── stopwatch.c/.h
    ├── dice.c/.h
    ├── morse.c/.h
    ├── snake.c/.h
    ├── counter.c/.h
    └── sysinfo.c/.h
```

Каждый модуль сам создаёт свой `View` с моделью (`ViewModelTypeLocking`),
таймеры и подписку на уведомления, а наружу отдаёт `*_alloc`, `*_free` и
`*_get_view`. Новый модуль добавляется одной строкой `flipper_os_add_module()`
в `flipper_os.c`.
