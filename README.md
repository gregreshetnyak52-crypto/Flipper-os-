# FlipperOS

Кастомная прошивка для [Flipper Zero](https://flipperzero.one) на базе
[Unleashed](https://github.com/DarkFlippers/unleashed-firmware) (релиз
`unlshd-093`). Внутри всё, что есть в Unleashed, плюс собственное приложение
**Flipper OS Toolkit** прямо в главном меню.

Что добавлено поверх Unleashed:

- **Пункт «Flipper OS» в главном меню** с анимированной иконкой-чипом.
- **Flipper OS Toolkit v1.3** входит в прошивку (`apps/Tools/flipper_os.fap`).
- **Анимация FlipperOS на рабочем столе**: заставка с логотипом добавлена
  в набор анимаций дельфина (см. [`firmware/patches`](firmware/patches)).
- **Брендинг**: прошивка называется `FlipperOS`, файлы сборки — `flipperos-<версия>`.
- **CI**: GitHub Actions собирает пакет обновления на каждый пуш, а для тега
  `v*` публикует релиз.

## Flipper OS Toolkit

| **Timer** | Обратный отсчёт до 99:59 с прогресс-баром и сигналом (звук, вибро, LED). Идёт и звонит, даже если открыт другой модуль, — экран таймера всплывает сам. Сигнал звучит 30 с | ←/→ — минуты/секунды, ↑/↓ — значение, удержание OK — пресеты 1…60 мин, OK — старт/пауза, ← — сброс, любая кнопка глушит сигнал |

| **Flashlight** | Белый светодиод: постоянно, стробоскоп или маяк; 4 уровня яркости; подсветка экрана не гаснет | OK — вкл/выкл, ↑/↓ — яркость, ←/→ — режим |
| **Dice Roller** | От 1 до 4 костей d4…d100 с анимацией и вибро | ↑/↓ — грани, ←/→ — количество, OK — бросок |
| **Coin & 8-Ball** | Монетка (орёл/решка), «Да/Нет» со счётом результатов и Magic 8-Ball с 20 классическими ответами | ←/→ — режим, OK — бросок/вопрос |
| **Password Gen** | Генератор паролей и PIN-кодов на аппаратном ГСЧ: 4…32 символа, 4 набора символов (гарантированно есть символ каждого класса), оценка энтропии в битах | ↑/↓ — длина, ←/→ — набор символов, OK — новый пароль |
| **Morse Beacon** | Сообщение азбукой Морзе через LED, LED+вибро или LED+звук. Есть свой текст с экранной клавиатуры (буквы и цифры, `_` — пробел) | ←/→ — сообщение, ↑ — выход, ↓ — повтор, OK — старт/стоп, удержание OK на «своём тексте» — редактировать |
| **Snake** | «Змейка» 32×14 с ускорением. Два режима: сквозные края или стены, у каждого свой рекорд | Стрелки — поворот, OK — старт/пауза, ↑/↓ между играми — режим |
| **Reaction Test** | Тест реакции: после случайной паузы экран и LED вспыхивают, нужно нажать любую кнопку. Время в мс, среднее за 5 попыток, рекорд. Фальстарт засчитывается | OK — начать, любая кнопка — реакция |

| **System Info** | Имя, заряд, напряжение, ток и температура АКБ, свободная память, аптайм, дата и время | — |

Рекорды, статистика «помидоров», значение счётчика и настройки всех модулей
(кости, Морзе и свой текст, фонарик, таймер, генератор паролей) сохраняются
на SD-карте в `apps_data/flipper_os/settings.dat`. Сами пароли нигде
не сохраняются. При обновлении с 1.0–1.2 старые данные переносятся
автоматически. Внизу меню — **Settings** (сброс сохранённых данных Toolkit)
и **About** (версия Toolkit, ветка/коммит и происхождение прошивки, дата сборки).

Приложение совместимо и с официальной прошивкой: там оно ставится как обычный
`.fap` в **Apps → Tools**.

## Что даёт Unleashed

Всё это в прошивке FlipperOS работает «из коробки» — это код и функции самого
Unleashed, подключённого субмодулем (см. [«Как перенесены функции
Unleashed»](#как-перенесены-функции-unleashed) ниже):

- **SubGHz** — расширенный список поддерживаемых протоколов ворот/шлагбаумов/
  сигнализаций сверх официальной прошивки, приём и повтор на частотах вне
  заводского региона (по умолчанию выключено, включается файлом-флагом
  `dangerous_settings` на SD, см. ниже), сохранение и повтор сырых сигналов,
  режим анализа частоты (Frequency Analyzer), поддержка внешних модулей
  (SubGHz Rx/Tx-модули на CC1101).
- **125 кГц RFID (LF-RFID)** — чтение, запись, эмуляция и брутфорс EM4100 и
  совместимых карт с добавочными настройками из Unleashed.
- **NFC** — чтение/эмуляция/запись Mifare Classic/Ultralight/DESFire,
  восстановление ключей Mifare Classic (mfkey), больше NFC-словарей ключей,
  чем в официальной прошивке.
- **iButton** — чтение, запись и эмуляция Dallas/Cyfral/Metakom ключей.
- **Infrared** — универсальный пульт с расширенной базой ИК-кодов бытовой
  техники и учебный/анализирующий режим сигнала.
- **BadUSB** — раскладки клавиатур сверх стандартного набора, доп. режимы
  скрипта.
- **GPIO** — управление пинами, USB-UART bridge, 1-Wire.
- **U2F** — аппаратный ключ двухфакторной аутентификации.
- **Bluetooth/BLE** — расширенные настройки сопряжения и профиля клавиатуры/
  мыши по BLE (наследие Unleashed).
- **Настройки региона и мощности** — можно вручную выбрать регион и включить
  расширенный диапазон/мощность передачи через `dangerous_settings`
  (файл `yes_i_want_to_destroy_my_flipper` в `/ext/subghz/assets/`).
  **В нашей сборке это, как и в Unleashed, выключено по умолчанию** — включать
  сознательно и на свою ответственность: передача вне сертифицированных
  диапазонов может быть незаконна в вашей стране и потенциально
  перегреть/повредить радиомодуль.
- **Расширенный набор тем и анимаций дельфина**, доп. игры и Apps → Tools
  из самого Unleashed (Clock, Snake и т.д. — не путать с одноимёнными
  модулями нашего Toolkit, это отдельные, штатные для Unleashed приложения).

Мы не переписывали код этих функций — они входят как есть, вместе с
исходниками Unleashed. Подробности ниже.

## Установка прошивки

1. Скачайте `flipper-z-f7-update-flipperos-*.tgz` из артефактов workflow
   **Build FlipperOS firmware** (вкладка *Actions*) или из *Releases*.
2. В [qFlipper](https://flipperzero.one/update) нажмите
   **Install from file** и выберите этот `.tgz`.

   Без компьютера: распакуйте архив в `update/` на SD-карте и на Flipper
   откройте `update/f7-update-flipperos-*/update.fuf` через **Archive → Run in App**.

Вернуться на официальную прошивку или Unleashed можно тем же способом.

## Сборка

Прошивка (нужны Linux/macOS, git и Python 3; тулчейн `fbt` скачает сам):

```sh
git clone https://github.com/gregreshetnyak52-crypto/flipper-os-
cd flipper-os-
firmware/build.sh                  # → firmware/unleashed/dist/f7-C/*.tgz
firmware/build.sh flash_usb_full   # собрать и сразу прошить по USB
```

Только приложение, под любую прошивку, через
[ufbt](https://github.com/flipperdevices/flipperzero-ufbt):

```sh
pip install --upgrade ufbt
cd flipper_os
ufbt            # → dist/flipper_os.fap
ufbt launch     # собрать, загрузить и запустить по USB
```

## Как перенесены функции Unleashed

Функции Unleashed выше не переписывались и не портировались вручную — весь
Unleashed подключён как git-субмодуль `firmware/unleashed` (закреплён на
релизе `unlshd-093`) и собирается целиком, штатным `fbt`. Мы не трогаем
список приложений Unleashed — только добавляем в него один свой пункт:

```python
# firmware/overlay/fbt_options_local.py
FIRMWARE_APPS["default"].append("flipper_os")   # append, а не замена списка
```

Поэтому все приложения из штатного набора Unleashed (`main_apps`,
`system_apps`, `settings_apps`) остаются в прошивке без изменений — включая
`dangerous_settings` и прочее, описанное выше. Подробный список того, что
именно добавлено сверху Unleashed, — в первом разделе этого README.

## Как устроен репозиторий

```
flipper_os/                 приложение Flipper OS Toolkit
├── application.fam         манифест (MENUEXTERNAL: пункт главного меню)
├── flipper_os.c            точка входа, ViewDispatcher, меню
├── settings.c/.h           сохранение состояния на SD
└── modules/                по одному View на модуль
firmware/
├── unleashed/              git-субмодуль Unleashed, закреплён на unlshd-093
├── overlay/                файлы, копируемые поверх Unleashed
│   ├── fbt_options_local.py            имя прошивки и состав меню
│   ├── assets/icons/MainMenu/FlipperOS_14/   иконка главного меню
│   └── assets/dolphin/external/L1_FlipperOS_128x64/   анимация рабочего стола
├── patches/                *.patch к исходникам Unleashed (см. README там)
│   └── 0001-flipperos-desktop-animation.patch   анимация в манифесте дельфина
├── tools/make_animation.py генератор кадров анимации (нужен Pillow)
└── build.sh                сброс → патчи → overlay → приложение → ./fbt
```

Unleashed не копируется в репозиторий целиком, а подключён субмодулем.
Поэтому переход на новую версию сводится к одной команде:

```sh
cd firmware/unleashed && git fetch --depth 1 origin tag unlshd-XXX && git checkout unlshd-XXX
cd ../.. && git add firmware/unleashed && git commit -m "Bump Unleashed to unlshd-XXX"
```

Unleashed распространяется под лицензией GPL-3.0, поэтому собранная прошивка FlipperOS подпадает под ту же лицензию.
