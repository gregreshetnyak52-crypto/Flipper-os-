FlipperOS v1.3.1 — restores the Unleashed community apps that were missing in v1.3.

**If you installed v1.3, update to this release.** v1.3 was built from the
Unleashed sources only, which is Unleashed's "clean" flavour: the firmware,
Sub-GHz protocols, NFC/RFID/iButton/IR and the built-in apps were all there,
but the community apps that Unleashed releases put on the SD card (Sub-GHz
bruteforcer, spectrum analyzer, ESP32/NRF24/GPS tools, games and more) were not.

## Install

Pick one package and open it in [qFlipper](https://flipperzero.one/update) →
**Install from file** (or unpack it into `update/` on the SD card and run
`update.fuf` from **Archive → Run in App**):

- `flipper-z-f7-update-flipperos-v1.3.1.tgz` — firmware + **base app pack**:
  the same apps as a plain Unleashed release (77 apps + TOTP plugins).
- `flipper-z-f7-update-flipperos-v1.3.1e.tgz` — firmware + base + **extra
  app pack**: the same as the Unleashed "e" release (about 360 apps).

Both carry the same firmware; the packs are SD card resources. Your own files
on the SD card are not touched.

## What changed

- The update packages now include the app packs from
  [xMasterX/all-the-plugins](https://github.com/xMasterX/all-the-plugins)
  (release `9sep2026p2`, the one built for the Unleashed version we use).
  The files are verified against pinned checksums, and CI checks that every
  file of the packs is really inside the finished package.
- A second, "e" package with the extra pack.
- Nothing else changed: firmware, Flipper OS Toolkit 1.3 and Patrol are as in v1.3.

## Files

- `flipper-z-f7-update-flipperos-v1.3.1.tgz` — update package, base pack
- `flipper-z-f7-update-flipperos-v1.3.1e.tgz` — update package, base + extra pack
- `flipper-z-f7-full-flipperos-v1.3.1.dfu` — full firmware image for DFU flashing (no apps)
- `patrol.fap` — Patrol as a standalone app for other firmwares
- `patrol-report.html` — offline log verifier and report for Patrol
