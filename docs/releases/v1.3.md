FlipperOS v1.3 — Unleashed `unlshd-093` + Flipper OS Toolkit 1.3 + Patrol.

## Install

Download `flipper-z-f7-update-flipperos-v1.3.tgz` below and open it in
[qFlipper](https://flipperzero.one/update) → **Install from file**.
Without a computer: unpack it into `update/` on the SD card and run
`update/f7-update-flipperos-v1.3/update.fuf` from **Archive → Run in App**.

## What's new

**Flipper OS Toolkit 1.3** (main menu → Flipper OS)
- New modules: Pomodoro, Password Gen, Coin & 8-Ball, Reaction Test
- Stopwatch keeps 50 laps with splits; Timer has presets and rings from any
  module; Snake has a walls mode; Morse Beacon sends your own text
- Resets in Settings apply immediately; data from 1.0–1.2 is migrated

**Patrol** (Apps → Tools → Patrol) — guard tour and inspection rounds
- Tap NFC, 125 kHz RFID or iButton checkpoints along a route
- Tamper-evident log: every record is HMAC-SHA-256 signed in a chain; the
  site key and admin PIN are encrypted with the device's secure enclave
- Receipt code after each round
- `patrol-report.html` (attached) verifies logs offline and builds reports
- New, not yet field-tested on hardware: please report issues

**Firmware**
- FlipperOS desktop animation
